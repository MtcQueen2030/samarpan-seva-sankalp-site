# Samarpan Seva Sankalp (T) — Website Starter

A responsive static NGO website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content and sections
- `styles.css` — responsive styling
- `script.js` — mobile navigation, current year and demo contact form

## Preview on your computer
1. Extract the ZIP.
2. Open the `samarpan_ngo_website` folder.
3. Double-click `index.html` to open it in Chrome.

Internet is needed for the Google Fonts to load; the site layout still works without them.

## Before publishing
1. Confirm the organisation's exact legal name and any permitted use of `(T)`.
2. Replace the placeholder email/location notes in `index.html` with verified public contact details.
3. In `script.js`, set `ORGANISATION_EMAIL` to the official email address. The form then opens the visitor's email app; it does not send silently.
4. Replace the illustrative emblem and SVG artwork with the organisation's approved logo and real project photos, where available.
5. Publish only verified programme, registration and impact information. Do not claim 12A, 80G, FCRA, government endorsement or other certification unless granted and verifiable.
6. For direct web-form submissions, connect a form provider or backend; a static HTML site cannot securely store or email submissions on its own.

## Free hosting test (GitHub Pages)
1. Create/sign in to a GitHub account.
2. Create a **public** repository, for example `samarpan-seva-sankalp-site`.
3. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root (not inside an extra nested folder).
4. Open **Settings → Pages**.
5. Under build/deployment, select **Deploy from a branch**; choose `main` and `/(root)`, then Save.
6. Wait for the published URL shown on the Pages settings screen. It is usually `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`.
7. Test it on a phone and desktop. The first deployment may take a few minutes.

GitHub Pages is suitable for a static preview. Do not upload private beneficiary data, identity documents, passwords or confidential records to a public repository.
